RACCOON RAMPAGE: THE LEGEND OF TRASH PANDA
v0.9 — FINAL ART EDITION

This build is a visual/polish milestone built from v0.8.

Highlights:
- Full title treatment: The Legend of Trash Panda
- More illustrated comic-book environments for all three arenas
- Animated Trash Panda with skin-specific accessories
- More distinctive enemy silhouettes and elite presentation
- Larger, more detailed boss artwork
- Stronger hit/critical feedback and visual flashes
- Ground props, halftone texture, parallax-style environment layers
- Speed-line feedback while moving quickly
- Expanded HUD combat stats
- Existing v0.8 gameplay, progression, bosses, evolutions, challenge, achievements, sound and iPhone-friendly controls retained

HOW TO PLAY:
Open index.html in a modern browser. On iPhone, the game is best hosted through GitHub Pages or another HTTPS web host.

For GitHub Pages, replace the existing index.html with this build's index.html.
